# TESMS

An Android Flutter application that enables your device to act as a local SMS server, allowing developers to manage and send SMS through an API.

## Features

* **SMS Integration:** Requests the necessary permissions and interacts with the device's native SMS capabilities.
* **Local Server Hosting:** Runs a local server directly on the device.
* **Network Identification:** Automatically detects the device's current local network IP address.
* **Authentication:** Generates unique API keys to secure communication with the local server.
* **Persistent Storage:** Stores application settings and user configurations locally.

## How to Use

1. Download and install the APK on your Android device.
2. Grant the required SMS and other permissions.
3. Start the local server from the app.
4. Use the displayed IP address and API key to connect to the server.

Simply **download the APK, install it, and start using TESMS.**
